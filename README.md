# Dobble generator

A simple and lightweight Python script that generates general Dobble games of prime power order.

## 📋 Features
* **Fast & Lightweight:** Consists of a single file, easy to copy and run.
* **No Complex Setup:** No external configurations needed.

## ⚙️ Requirements
Before running the script, make sure you have Python 3.x installed.
* External libraries: `galois`

If your script requires external libraries, users can install them using:
```bash
pip install -r requirements.txt
```
*(Or just list the command: `pip install library_name`)*

## 🚀 How to Use

### Option 1: Quick Copy & Paste (Recommended)
1. Open [script.py](URL_TO_YOUR_SCRIPT_FILE) in this repository.
2. Click the **"Copy raw contents"** icon (the two overlapping squares) in the top-right corner of the code box.
3. Paste the code into a local file named `script.py` on your computer.
4. Run it via terminal:
   ```bash
   python script.py
   ```

### Option 2: Clone the Repository
```bash
git clone https://github.com
cd YOUR_REPOSITORY_NAME
python script.py
```
